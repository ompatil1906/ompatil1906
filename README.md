## Featured Projects

### WARDEN — Autonomous Revenue Protection Agent

[![WARDEN](https://img.shields.io/badge/GitHub-WARDEN-181717?style=flat-square&logo=github)](https://github.com/ompatil1906/Warden)
[![Live Demo](https://img.shields.io/badge/Live-Demo-0A66C2?style=flat-square)](https://warden-ebon.vercel.app)

An autonomous B2B purchasing agent designed to protect merchant revenue from high-velocity stockouts.

### What it does

- Monitors live sales velocity
- Predicts stockout risk
- Calculates revenue at risk
- Makes **BUY / WAIT / ESCALATE** decisions
- Searches and negotiates with suppliers
- Executes bounded restocking workflows
- Uses deterministic safety gates before money movement
- Implements Ed25519-signed mandate chains
- Integrates Razorpay payment execution
- Reconciles payments through verified webhooks
- Provides real-time agent telemetry and audit trails

### Tech Stack

`Python` `FastAPI` `LangGraph` `LLMs` `REST APIs` `Razorpay` `WebSockets` `Ed25519` `React` `TypeScript`

**Repository:**  
https://github.com/ompatil1906/Warden

### HelpIQ — Autonomous Multi-Agent Customer Support Platform

[![HelpIQ](https://img.shields.io/badge/GitHub-HelpIQ-181717?style=flat-square&logo=github)](https://github.com/ompatil1906/HelpIQ-Autonomous-Multi-Agent-Customer-Support-Platform)

A production-oriented multi-agent AI platform for autonomous customer support ticket resolution.

### Architecture

```text
Customer Ticket
      ↓
   Triage
      ↓
  Retrieval
      ↓
   Resolver
      ↓
  Guardrail
      ↓
 Auto-Resolution / Human Review
````

### What it does

* Multi-agent ticket processing
* RAG-based knowledge retrieval
* LLM-powered response generation
* Human-in-the-loop approvals
* Policy-based guardrails
* JWT authentication
* Role-Based Access Control
* Multi-tenant data isolation
* Async processing with Celery + Redis
* PostgreSQL persistence
* Pinecone vector search with TF-IDF fallback
* Audit logging
* Real-time WebSocket events

### Tech Stack

`Python` `FastAPI` `LLMs` `RAG` `PostgreSQL` `Redis` `Celery` `Pinecone` `React` `JWT` `RBAC`

**Repository:**
https://github.com/ompatil1906/HelpIQ-Autonomous-Multi-Agent-Customer-Support-Platform
